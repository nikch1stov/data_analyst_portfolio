# Исследование стартапов

Анализ исторических данных о финансировании стартапов с 1999 по 2014 год. Цель в том, чтобы найти закономерности по объемам, типам и динамике инвестиций и дать инвестору рекомендации по стратегии на начало 2015 года.

## Стек

Python, pandas, matplotlib, seaborn, Jupyter Notebook

## Данные

Датасет `cb_investments.csv` из базы данных стартапов. В нем 54 294 компании и 40 столбцов (название, рынок, объем финансирования, статус, страна, раунды и другие). После очистки от дубликатов, пропусков и выбросов осталось 35 492 компании.

## Что сделано

1. Предобработка данных, приведение типов, удаление дубликатов и пропусков.
2. Сравнение компаний по срокам финансирования.
3. Анализ рыночных сегментов и их динамики.
4. Анализ типов финансирования и доли возвращенных средств.
5. Итоговые выводы и рекомендации заказчику.

## Выводы

- Компании, которые привлекали финансирование дольше года, составляют 30% от общего числа, но получают 61,9% всех вложений.
- Типичный размер раунда упал с 4,5 млн USD в 2005 году до 0,6 млн USD в 2014 году, а число раундов росло до 2013 года.
- В 2014 году выросло финансирование только у трех массовых сегментов: medical, real estate и internet.
- Venture доминирует по объему, но доля возврата у него низкая. Debt financing возвращает деньги надежнее.
- Seed популярен, но у него самая низкая доля возврата к 2014 году.
- Данные за 2014 год неполные, поэтому выводы по нему предварительные.

## Рекомендации заказчику

1. Рассматривать medical как основной сегмент, потому что он рос с 2010 по 2014 год без провалов.
2. Использовать venture как основной инструмент, а на зрелых стадиях подключать debt financing.
3. Не входить в компании с одним раундом финансирования.
4. Не делать seed основным инструментом.

## Как запустить

1. Установите Python 3.9 или новее.
2. Установите библиотеки командой `pip install pandas matplotlib seaborn jupyter`.
3. Положите файл `cb_investments.csv` рядом с ноутбуком.
4. Откройте `startup_analys.ipynb` в Jupyter Notebook и выполните ячейки по порядку.
