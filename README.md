# Портфолио аналитика данных

В репозитории собраны мои учебные проекты по анализу данных. В каждой папке лежит свой README с целью, стеком, выводами и инструкцией по запуску.

## Проекты

| Проект | Описание | Стек |
|:-------|:---------|:-----|
| [Исследование стартапов](startup_research) | Анализ финансирования стартапов с 1999 по 2014 год и рекомендации инвестору | Python, pandas, matplotlib, seaborn |
| [Анализ продаж и сезонности на рынке недвижимости](real_estate_sales_seasonality_analysis) | Время активности объявлений и сезонность рынка Санкт-Петербурга и Ленинградской области | SQL (PostgreSQL) |
| [Дашборд ресторанов Саранска](https://datalens.yandex/w5haqrcu0wxgg) | DAU, CR, LTV и Retention для рынка доставки еды, май - июнь 2021 | SQL, Яндекс DataLens |

## Структура репозитория

- `startup_research` - ноутбук с анализом и README
- `real_estate_sales_seasonality_analysis` - SQL-запросы, аналитическая записка и README
